# 放大彎的胞長梯推到 0.125 µm（2026-10-29 新增運行）

**為什麼要跑**：稿子裡的胞長條款說「細化到讀數不再變」即可解除，卻只報告到 0.5 µm（放大彎）與 0.75 µm（全器件，受 500 胞上限所限）。審稿人一定會問「那到底多細才夠」。放大彎全長只有 60 µm，0.25 µm＝240 胞、0.125 µm＝480 胞，**都還在求解器 500 胞的限制之內**，所以這個問題可以在同一個模型上直接回答。

**設置**（與既有放大彎記錄完全同一支腳本建幾何：`probe_amp.py` 的 `_build`，未重打字）：
直段 20 µm ＋ S 彎（Δy = 5 µm，跨 20 µm）＋ 直段 20 µm，總長 60 µm；Lumerical MODE v251 EME，單一胞組、直胞；Si 220 nm、寬 500 nm、SiO₂ 下包層、空氣上包層；單頻 1.55 µm。
讀數＝S 矩陣每個輸入的列和（兩個輸入相同，故並列兩值）。腳本：`second_solver/refine_amp.py`；結果：`refine_amp_results.json`；引擎日誌：`refine_bend20_m*_cell*_p0.log`。

## 事實（不是解釋）

1. **細化 40 倍（5 → 0.125 µm）仍然沒有收斂**：8 模的序列是 0.0085 % → 6.6 % → 1.15 % → 3.78 % → 12.7 % → 0.38 %，**跨 1494 倍**，非單調。
2. **基一大，跨幅變小但沒有消失**：32 模同一條梯子最小 2.913×10⁻³、最大 1.56×10⁻¹，**跨 53 倍**。
3. **最細那一點，兩個基反而靠攏**：0.125 µm 下 0.38 %（8 模）與 0.29 %（32 模），只差 1.31 倍 —— 都仍在 1.000 的兩個數量級之下，而同一個彎的精確解是無損的（FDE，見 `probe_bentfde.py`）。
4. 兩點重跑可重現：0.125 µm、8 模重跑仍為 3.821×10⁻³（兩次獨立運行）。
5. 每次運行耗時（單線程）：0.25 µm 8/32 模 = 45.5 / 143.7 s；0.125 µm 8/32 模 = 84.5 / 266.0 s。

## 對稿子的意義

**「細化到不再變」這條解除方式，在這個結構上做不到**：把胞細化 40 倍，讀數依然在 0.0085 %–12.7 % 之間跳；而在最細的胞上，兩個基反而同意到 0.3 % 左右 —— 也就是說，一個「已經收斂」的讀數依然可以比真值低兩個數量級。這比「沒有收斂」更強：收斂與否都不是判據，**讀數是不是器件量，取決於它有沒有被直胞樓梯污染**。
